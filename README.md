# E-Commerce Business Knowledge Repository

## Description

This repository contains structured knowledge about an E-Commerce Business System.

## Entities

- Customers
- Products
- Inventory
- Orders
- Payments
- Suppliers

## Knowledge Components

The repository also contains:

- Relationships between business entities
- Business rules
- Structured JSON data

## Example Relationships

Customer -> PLACED -> Order

Order -> CONTAINS -> Product

Product -> SUPPLIED_BY -> Supplier

- Python
- JSON
